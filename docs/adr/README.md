# Architecture Decision Records

One file per decision, numbered: `NNNN-kebab-title.md`, titled
`# ADR NNNN — <decision as a sentence>`, with a status line
`**Status**: Accepted · **Date**: YYYY-MM-DD` and the sections
Context → Decision → Consequences.

Rule: an accepted ADR is not edited — it is superseded by a new ADR.
Research behind these decisions: `docs/PROJECT.md` (sources and journal).
