# Landing-page media: notice

This folder holds the media for the shattered-glass landing page: the clip
atlases (`atlas-*.mp4`), their first frames (`frame0-*`), the poster atlases
(`stills-*`) and `tilemap.json`, which describes them. All of it is generated by
`apps/web/scripts/build-landing-atlas.py`.

## Synthetic development media

Until the real media arrive, the files here are synthetic test patterns made
by `build-landing-atlas.py --synthetic`: numbered, slowly moving colour fields
drawn with ffmpeg's lavfi sources. They contain no third-party material.
`tilemap.json` records which kind is shipped
(`"synthetic": { "clips": true, "posters": true }` for the test patterns).

## Safety

Every clip goes through ffmpeg's `photosensitivity` filter (WCAG 2.3.1, no
flashes) and the build fails on a high score. The owner reviews the numbered
debug grid in `media/out/` before real media go live.
