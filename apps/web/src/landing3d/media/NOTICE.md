# Landing-page media: notice

This folder holds the media for the floating-glass landing page: the clip
atlases (`atlas-*.mp4`), their first frames (`frame0-*`), the poster atlases
(`stills-*`) and `tilemap.json`, which describes them. All of it is generated by
`apps/web/scripts/build-landing-atlas.py`.

## What is shipped

Since 2026-10-12 the clips and posters are real media chosen by the project
owner (14 clips, 8 photos). Some clips were trimmed, cropped (to keep text
overlays out of the shards) or turned into back-and-forth loops, and one had
flashes softened, before the atlas was built. `tilemap.json` records that real
media are shipped (`"synthetic": { "clips": false, "posters": false }`);
`build-landing-atlas.py --synthetic` still makes test patterns for development.

## Safety

Every clip goes through ffmpeg's `photosensitivity` filter (WCAG 2.3.1, no
flashes) and the build fails on a high score. The owner reviews the numbered
debug grid in `media/out/` before real media go live.
